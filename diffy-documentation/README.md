# 👋 Welcome

### Allow IP address 138.201.56.149 (IPV6 2a01:4f8:172:1189::2)

First things first. If you have any difficulties creating screenshots with Diffy, make sure your CDN/Firewall doesn't block our workers. Here is how you do it in [Cloudflare](https://developers.cloudflare.com/waf/custom-rules/use-cases/allow-traffic-from-ips-in-allowlist/).

There is an option in Project Settings > Advanced > Optimization to enable/disable a single IP address. Please make sure it is enabled for your site.
