# Local development

We have open-sourced our [screenshots worker](https://github.com/DiffyWebsite/diffy-worker). You can use it to take screenshots from your local website in development and upload them to Diffy. This will allow you to check your local site vs. screenshots from production (or any other environment).

We have come up with some integrations with common local development environments:

* [DDEV addon](ddev-add-on.md)
* [Lando integration](lando-integration.md)
* [Docksal integration](docksal.md)
* [Standalone docker container](standalone-docker-container.md)
* [Ngrok](ngrok.md)
