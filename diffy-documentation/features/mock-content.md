# Mock content

If new content constantly appears on the site, you can get a lot of false positives because of it. With Diffy, you can replace that content with "lorem ipsum" text, so you can still test the styles of the content, but false positives won't be triggered as the content itself is static.

Under Project Settings > Advanced > Mock Content you can add rules to replace content. You can target different selectors and replace them with different types of mocks: title, paragraph, image etc.
