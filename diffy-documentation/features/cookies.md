# Cookies

You can set custom cookies for Diffy workers.

### Bypass CDN

If you use CDN or reverse proxy like Varnish you can add a cookie to make sure you never hit cache.

### Consents

Another use-case is to set values so you are not asked to consent. For example, websites that promote alcohol require to provide a year of birth. Passing this popup can be done with the use of a cookie.
