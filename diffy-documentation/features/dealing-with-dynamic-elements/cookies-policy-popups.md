# Cookies Policy Popups

Here is a collection of cookie policy popups you would want to remove from screenshots and selectors to be used in project settings.



### OneTrust

[https://www.onetrust.com/products/cookie-consent/](https://www.onetrust.com/products/cookie-consent/)

Selector

```
#onetrust-consent-sdk
```



### Osano

[https://www.osano.com/cookieconsent](https://www.osano.com/cookieconsent)

Selectors

```
.osano-cm-window__widget
.osano-cm-window__dialog
```



### CookieBot

[https://www.cookiebot.com/](https://www.cookiebot.com/)

Selector

```
#CybotCookiebotDialog
```



### Consent Manager

[https://www.consentmanager.net/en/](https://www.consentmanager.net/en/)

Selector

```
#cmpwrapper
```



### CookieYes

[https://www.cookieyes.com/](https://www.cookieyes.com/)

Selector

```
.cky-consent-container
```



## Complianz for WordPress Cookie Consent

[https://complianz.io/](https://complianz.io/)

Selector

```
.cmplz-cookiebanner
#cmplz-cookiebanner-container
```
